 # 🔋 TEMIFY – Mobile Power Bank Rental Service

TEMIFY is a mobile assistant robot-based power bank rental service that allows users to easily rent and return portable batteries through an automated system.

The service integrates a robot platform, mobile application, Arduino-based hardware, and a real-time server to provide a smooth and convenient rental experience.

[![Temify Demo](https://www.youtube.com/watch?v=VbqeodgSBok)


## 📌 Project Summary

- Users authenticate through the mobile app  
- Available power banks can be rented via the TEMI robot  
- Battery status and rental time are managed in real-time  
- Users can return or extend rentals easily  
- The system supports automatic tracking and management of rental data  

This project focuses on improving accessibility and convenience by combining robotics with smart rental management technology.


## 🧩 System Structure

The system consists of:
- TEMI Robot Interface  
- Mobile Application  
- Firebase Realtime Database  
- Arduino-based Hardware Control  
- Server for rental coordination and data management  


## 🎯 Main Features

- Power bank rental & return automation  
- User authentication system  
- Real-time battery status tracking  
- Rental time monitoring and extension  
- Integrated robot display and interaction  


## 🚀 Purpose

TEMIFY aims to reduce inconvenience caused by low battery situations in public spaces and provide a smart, contactless rental experience using robotics and IoT technology.
